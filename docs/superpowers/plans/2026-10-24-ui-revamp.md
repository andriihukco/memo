# UI Revamp Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild the Memo Mini App UI on strict shadcn/ui with light and dark themes, 2026 iOS/Android flows, and in-app compose.

**Architecture:** Phase 0 builds the foundation serially: shadcn, tokens, themes, shell, shared patterns, helpers and guard tests. Phase 1 runs six screen agents in parallel. Each agent works in its own git worktree off the Phase 0 tip and owns separate files. Phase 2 merges, fills the locales, deletes the old UI and `framer-motion`, and verifies everything in the browser.

**Tech Stack:** Next.js 14 (app router), React 18, Tailwind 3.4, shadcn/ui (new-york, zinc, Radix), vaul, sonner, next-themes, Recharts (via shadcn Chart), lucide-react, D3 (graph only), vitest + fast-check, Supabase, Gemini.

**Spec:** `docs/superpowers/specs/2026-10-24-ui-revamp-design.md`. Executors read the spec section each task cites.

## Global Constraints

**Components and styling**
- Only shadcn/ui components live in `src/components/ui/`. Add them with `npx shadcn@2.1.8 add <name>`. Do not install any other UI kit.
- App behaviour such as haptics goes in wrappers outside `components/ui`.
- Icons: `lucide-react` only.
- Theme classes: `:root` = light, `.dark` = dark. Use `next-themes` with `attribute="class" defaultTheme="system" enableSystem`.
- No arbitrary Tailwind values in new code. That covers `text-[`, `bg-[#`, `rounded-[`, `z-[`, hex colours in TSX, `muted-foreground/<n>`, and inline `style` colours. The guard test (Task 3) enforces this.
- Minimum text size is `text-xs` (12px).
- Primary controls are at least 44×44px; every target is at least 24×24px.
- Type ramp:

| Role | Classes |
|---|---|
| Large title | `text-3xl font-bold tracking-tight` |
| Title | `text-xl font-semibold` |
| Headline | `text-base font-semibold` |
| Body | `text-base` |
| Subhead | `text-sm` |
| Footnote | `text-xs text-muted-foreground` |

**Contrast:** text ≥ 4.5:1, non-text and `--input`/`--ring` ≥ 3:1, in both themes.

**Strings and dates**
- Every user-facing string, aria-labels included, goes through `useI18n().t` or `tp`.
- New keys go only in `src/i18n/en.json` and `uk.json` during Phase 1, namespaced: `shell.*`, `journal.*`, `entry.*`, `compose.*`, `insights.*`, `graph.*`, `you.*`, `paywall.*`, `onboarding.*`.
- Dates and numbers go only through `src/lib/format.ts`. Never `toLocaleDateString('uk-UA')` and never a fixed offset.

**Interaction**
- Reversible destroys (entries, widgets, categories, graph nodes, reports) use `useUndoableDelete`: no confirm dialog, a Sonner "Deleted · Undo" toast, and the server commit after 5000ms.
- Only account deletion uses `AlertDialog`.
- No clickable `div` or `span`. Use `<button>` or `<Link>`.
- Every Drawer and Dialog has a Title, visually hidden if necessary.

**Motion:** new code must not import `framer-motion`. Sheets use vaul. Animations come from `tailwindcss-animate`. Everything respects reduced motion.

**Commits:** conventional commits, ending with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **A delete is pending when the user closes the Mini App or switches tabs.** The commit must still happen: flush on `pagehide`/`visibilitychange`. Pending deletes must survive route changes because the store lives at module level. Tests are in Task 4 and Task A.
2. **Compose is sent twice (double tap) or while offline.** Exactly one request, or none while offline, and the draft is kept. Tested in Task B.
3. **The user picked Light explicitly, then Telegram fires `themeChanged` to dark.** The theme stays Light. Only "System" follows Telegram. Tested in Task 2.
4. **An old deep link from the bot is opened** (`/miniapp/reports?id=…`, `/miniapp/subscriptions`, `/miniapp/dashboard`). It must land on the new route with its query preserved. Tested in Task 5.
5. **A day group spans midnight across a DST change, in a non-UTC timezone and an RTL locale (`ar`).** The entry must sit under the correct local day, and labels must be correct. Tested in Task 4.
